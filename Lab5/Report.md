## Theoretical Notes

A context-free grammar is in Chomsky Normal Form when every production has one of the forms:

- `A -> BC` where `A, B, C` are nonterminals;
- `A -> a` where `a` is a terminal.

To reach this form, the grammar must be cleaned from epsilon rules and unit rules, and useless symbols must be removed before binarization and terminal isolation in longer right-hand sides.

The order of transformations matters. If unit rules are removed before epsilon elimination, some equivalent productions may be missed; if inaccessible and nonproductive symbols are removed too early, the grammar can be simplified incorrectly. The implemented order is the same as the required one from the task and is safe for this variant.

Let $G = (V_N, V_T, P, S)$ be a context-free grammar. The implementation relies on these definitions:

1. Nullable nonterminal: $A \in V_N$ such that $A \Rightarrow^* \epsilon$.
2. Productive nonterminal: $A \in V_N$ such that $A \Rightarrow^* w$ with $w \in V_T^*$.
3. Accessible symbol: symbol reachable from $S$ in some sentential form.

The CNF conversion then enforces for each rule either a single terminal on the right side or exactly two nonterminals.

### Internal representation

Productions are stored as tuples, for example:

- `A -> b A B` is stored as `("b", "A", "B")`
- `A -> ε` is stored as `()`

This representation makes transformations simpler because symbols are already tokenized and immutable.

### Code excerpt: building the grammar object

The constructor is intentionally simple and uses plain Python collections.

```python
class Grammar:
	def __init__(self, VN, VT, P, S):
		self.VN = set(VN)
		self.VT = set(VT)
		self.P = {left: set(rights) for left, rights in P.items()}
		self.S = S
```

### Code excerpt: epsilon elimination strategy

For every production containing nullable symbols, all valid variants are generated by removing nullable positions in combinations (except the empty right side, unless it is allowed for the start symbol).

```python
for left, rights in g.P.items():
	for rhs in rights:
		if len(rhs) == 0:
			continue

		new_productions[left].add(rhs)
		nullable_positions = [i for i, symbol in enumerate(rhs) if symbol in nullable]

		for count in range(1, len(nullable_positions) + 1):
			for removed in combinations(nullable_positions, count):
				removed_set = set(removed)
				candidate = tuple(
					symbol for i, symbol in enumerate(rhs) if i not in removed_set
				)
				if candidate:
					new_productions[left].add(candidate)
```

### Code excerpt: unit production elimination

The algorithm computes a unit-closure for each nonterminal and then copies only non-unit rules from all reachable nonterminals.

```python
for nt in g.VN:
	closure = {nt}
	stack = [nt]
	while stack:
		current = stack.pop()
		for rhs in g.P.get(current, set()):
			if self._is_unit_rule(rhs) and rhs[0] not in closure:
				closure.add(rhs[0])
				stack.append(rhs[0])
	unit_closure[nt] = closure
```

### Code excerpt: CNF conversion

The CNF conversion has two phases:

1. replace terminals from long right-hand sides with helper nonterminals (`T1 -> a`, `T2 -> b`);
2. binarize right-hand sides longer than 2 using chain nonterminals (`X1`, `X2`, ...).

```python
if len(rhs) <= 1:
	replaced[left].add(rhs)
	continue

replaced_rhs = []
for symbol in rhs:
	if symbol in g.VT:
		if symbol not in terminal_map:
			new_nt = g._fresh_nonterminal(prefix="T")
			g.VN.add(new_nt)
			replaced.setdefault(new_nt, set())
			replaced[new_nt].add((symbol,))
			terminal_map[symbol] = new_nt
		replaced_rhs.append(terminal_map[symbol])
	else:
		replaced_rhs.append(symbol)
```

## Transformation Result for Variant 18

Below is the concise interpretation of what changes at each stage and why this is correct.

### 1. After epsilon-production elimination

Epsilon rule `A -> ε` is removed and all nullable combinations are generated where `A` appeared in right-hand sides.

### 2. After renaming elimination

Unit productions like `S -> B`, `A -> S`, and `C -> B` are removed by unit-closure substitution. Their non-unit consequences are preserved.

### 3. After inaccessible-symbol elimination

`C` becomes inaccessible from `S` and is removed from the grammar.

### 4. After nonproductive-symbol elimination

All remaining nonterminals are productive in this variant after previous simplifications, so no additional symbol is removed at this stage.

### 5. Final CNF grammar

The program generates the following CNF grammar:

`VN = {S, A, B, D, T1, T2, X1}`
